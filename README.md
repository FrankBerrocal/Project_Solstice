Project Solstice


Quality Assurance Capstone

Summary

This project is based on a simulation of the evaluation of fraude in bank transactions using credit cards, to calculate the quality cost of changing / improving a machine learning process.

Other elements included are statistical assets (sample distributions, control charts, hypothesis test, R&R test, ANOVA test), project management (project initiation, planning, execution, control, 
and closing, applied to the academic project), DMAIC analysis for evaluation of model A vs model B and C when considering potential root causes of the simulated failure of the data model), 
Six Sigma alignment (the new model must provide world class quality due to the sensitivity of the bank transactions).  definition of a QMS (quality management system) based on ISO 9001 recommendations,
and the definition of the machine learning model.   

From an data engineering point of view, the simulation must create amounts of data inside the estimated ranges obtained from research using PERT estimation, the creation of that data should be automatic, 
the information should be uploaded in a S3 bucket, the processing should be made in Databricks using SQL for the processing of the data, and Python for the creation of the machine learning models.
All visualizations will be drafted in Databricks and then moved to PowerBI (Fraud analysis and associated cost) and at least one page should include the calculations of operational cost of processing of 
transactions.   

The restrictions of the project are:   simulation must be automated, all cloud functionality will be done in AWS, visualizations should be presented in PowerBI, Python and SQL are the languages to go, 
analysis will be made using DMAIC, alignment to Six Sigma must be calculated, quality costs must calculated using the quality cost of each model, its effect on fraud detection, the cost of false positives, true positives, 
false negatives and true negatives, applied statistics research and analysis, the project structure, scrum development of tasks and a QMS.
